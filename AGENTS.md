# Multisim circuit work

- Follow the user's circuit structure, textbook method, and specified component models. Use stock Multisim parts and the simplest implementation that satisfies the requirements.
- Use Native for schematic edits, layout inspection, interactive simulation, and supported numerical analyses. Reuse upstream edit batches and checks. Hand off to COM only for a required COM capability, cross-check, or explicit request.
- Verify electrical connectivity with native pins, nets, or netlist evidence. Wires touching on screen are insufficient. Check layout and collisions separately, then verify behavior with relevant input cases or waveform samples.
- Place parts to shorten their busiest connections before routing. Keep power and ground leads short. End each branch at a native junction placed where the visible lines actually split. In `native_edit_batch`, use `route_wire` with the current connector coordinates, then `repair_wire_geometry` if endpoints are misaligned. Inspect the exported drawing for shared wire segments that split away from the junction dot. If an exported switch appears displaced, compare it with the live schematic before changing its wiring.
- Lay out connected pins before routing. Align simple stage-to-stage connections and indicators, and give shared signals one trunk with short branches. For long detours, inspect the affected pins and move the parts on a working copy when that simplifies the overall layout. Read the new pin positions before rerouting their attached wires. Compare selected routes with `native_simplify_wiring` and use `native_check_layout` to locate remaining wire and label collisions.
- When rearranging a connected block, use `native_compare_placements` to generate layouts for repeated branches or compare explicit candidates. Review module metrics and unroutable wires. Use the same image region before and after when demonstrating a layout change.
- For a whole sheet, use `native_plan_sheet_layout` with inferred or specified functional blocks and lock parts the user wants in place. Review the recommended placement and routing, apply it on the working copy, and examine the native comparison at the same scale.
- For a small crowded block, use `native_plan_local_placement` with explicitly movable components and junctions. Compare with fixed placement before applying a larger change.
- Use `native_preview_ordered_wiring` for matched pins that share a routing corridor. Apply reviewed plans with `native_apply_layout_plan` on the same working copy and request matched image regions when showing the result.
- Use a working copy when testing changes to a supplied circuit. Confirm the active document before saving or handing it off, and preserve the original unless the user requests in-place changes.
- When delivering a circuit, run the relevant simulation from the final saved file and report the observed results. Start with checks that cover the change and expand them when an issue or a relevant coverage gap warrants it.
- Keep fixtures, local configurations, and NI assets out of Git. Run the public unit suite with `python -m unittest discover -s tests -v`. Describe real Multisim checks separately from unit tests.
